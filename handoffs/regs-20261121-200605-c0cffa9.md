## Problems with the tools (this run was on Windows 11, Git for Windows)

- `tools/ship.sh` needs `flock`, which Git for Windows does not have: it stops at "could not get the lock".
  Worked round with a no-op `flock` on PATH (one shipper in the clone); the script itself ran unmodified.
- `tools/costs.py` finds no transcripts on Windows (0 responses, so the gate's check 8b would fail): Claude
  Code names the folder `C--Dev-hd6845-trace`, and the tool only replaces `/` and `.`. `tools/regs_costs.py`
  is `costs.py` with that one line changed (`re.sub(r'[^A-Za-z0-9_-]', '-', os.path.normpath(main_root))`);
  proposed for `costs.py`.
- `tools/mergecheck.py` (and `tools/newwork.sh`) need symlinks: on Windows that needs Developer Mode. With it
  off, the gate dies at `os.symlink` and `newwork.sh`'s `ln -s` silently copies `cache/` (7 GB) and `.venv`
  into the worktree. A line in `notes/workflow.md` for Windows collaborators would save the next one an hour.
- `/trace6845` says `python3 tools/costs.py`; fine here, but `python3` is the system Python, not the venv.
