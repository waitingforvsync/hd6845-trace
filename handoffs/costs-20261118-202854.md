Committed on main at the user's instruction (Matt Godbolt, in session: "commit and push it").

**What changed.** A main session is now credited with a package's commit only for the stretch in which it was
itself working on that package: it ran `tools/t.sh PACKAGE tool.py ...`, shipped that package's files with
`tools/ship.sh "..."`, or edited them (Edit/Write). A command that only mentions the scripts names no package and
counts for none. For a commit touching several packages a session is credited with those it worked on. Reviewers
and subagents are handled as before.

**Why.** The rule of 1add61d ("a tracing call between the response and the commit") matched substrings: a
`cat tools/t.sh` and a heredoc editing costs.py in a second session under the same git name (on Sonnet, doing
coordination) counted as tracing, and its responses landed on `lc2`, whose next commits came from another session.
The gate's check 8b failed `lc2` twice on work that was traced and reviewed on Fable only.

**Effect on the existing report** (same transcripts, old tool against new): `lc2` Fable 552 + Sonnet 5 -> Fable 552;
`tl3` 375 -> 344 responses and `tl4` 701 -> 689 (stretches between packages, now coordination); no other package
changes, and no package's model list changes except `lc2`'s.

own transcripts only); this change keeps the report's shape and fixes the cross-session case.
